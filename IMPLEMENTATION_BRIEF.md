# Arafath Tours — responsive design repair

## Execution prompt
Rebuild the broken generated layouts into one coherent, responsive Kerala travel website. Preserve Travelio's editorial sans/italic typography, cinematic imagery, rounded navigation, pastel travel stamps, generous spacing and playful destination ribbon. Use the verified Arafath business information. Every photograph must match its title; use distinct images within each page and never use gallery photographs as hero backgrounds.

Use a dedicated Kerala Tourism Kumarakom backwater video for the main hero. Restore the original closing sunset film requested by the client. Both films must be muted, inline, autoplaying and looping, with accessible pause controls. Provide video-specific poster frames. Keep document and navigation transitions white; never cover the page with a persistent colored wipe.

Replace absolute-positioned promise labels with four self-contained travel stamps in a responsive grid. Build a compact scalloped destination ribbon driven by GSAP ScrollTrigger. Use real GSAP and Lenis for restrained scroll smoothing and animation; disable motion for reduced-motion preferences. Keep all text readable without JavaScript. Avoid pinned mobile sections, arbitrary fixed heights and giant background stickers. Rebuild tour statistics into a balanced grid; show the published tour fee neatly and never display cab fares. Keep all existing routes working, including Kerala articles, gallery, contact and cab enquiries.

## Acceptance criteria
- One navigation and one main content layer per page; mobile layout uses the whole viewport with no overlapping headings, stamps or cards.
- Video autoplay + muted + playsinline + loop; no click-to-play hero or footer.
- Unique, accurately labelled photo cards; local client village waterway present in gallery.
- White page background and navigation transition; safe recovery on page restore/tab return.
- Tour, gallery, filters, menu, article links and WhatsApp cab enquiries remain functional.
- Responsive breakpoints for phones, tablets and desktop; readable spacing and touch targets.
- Validate HTML/local references/JS and publish the existing Site.
